# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-08-27

### Added

- Portable `research-code-complexity` Agent Skill with audit, plan, and explicitly authorized refactor modes.
- Research artifact/lifecycle classification and essential-versus-accidental complexity decisions.
- Scientific contracts and verification for deterministic, numerical, stochastic, statistical, ML, notebook, figure/table, and published artifacts.
- Layered YAML profiles, JSON Schema, templates, validator, tests, and four domain examples.
- Verified measurement guidance for twelve language/artifact categories.
- Fourteen decision-focused eval cases and fixtures.
- Claude Code plugin/marketplace packaging, CI, citation, attribution, launch copy, and social preview assets.

### Changed from upstream

- Replaced universal refactoring thresholds with contextual triage.
- Replaced production-maintainability assumptions with research-aware risk and evidence boundaries.
